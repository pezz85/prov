# Azienda Agricola Sassara

Sito web ufficiale dell'Azienda Agricola Sassara, produttori di vini pregiati nel cuore della Valpolicella.

## 🚀 Getting Started

### Prerequisiti

- Node.js 16+ e npm
- Git

### Installazione

1. Clona il repository:
   ```bash
   git clone <repository-url>
   cd sassara-vini
   ```

2. Installa le dipendenze:
   ```bash
   npm install
   ```

3. Avvia l'ambiente di sviluppo:
   ```bash
   npm run dev
   ```

## 🛠 Build

Per creare una build di produzione:

```bash
npm run build
```

## 🌐 Deployment

Il sito può essere deployato su Vercel o su qualsiasi altro servizio di hosting che supporti applicazioni React.

### Vercel

1. Fai il push del codice su GitHub
2. Vai su [Vercel](https://vercel.com) e importa il progetto
3. Lascia le impostazioni di default e fai clic su "Deploy"

## 📁 Struttura del Progetto

```
src/
├── components/      # Componenti React
├── assets/          # File statici
public/
├── images/          # Immagini del sito
```

## 📝 Note

- Assicurati che tutte le immagini siano ottimizzate per il web
- Le immagini dei vini vanno nella cartella `public/images/`
- Il sito è completamente responsive e funziona su tutti i dispositivi
